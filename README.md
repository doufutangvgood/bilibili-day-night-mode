# 哔哩哔哩日夜间模式

静默跟随系统主题，在哔哩哔哩全站自动切换日间和夜间（深色）模式。

## 特性

- 页面加载前应用主题，减少闪烁
- 首页使用 `bili_dark`，其他页面使用 `night-mode`
- 同步 `theme_style` cookie
- 监听系统主题变化并实时跟随
- 不弹窗，不模拟点击

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 `bilibili-day-night-mode.user.js`。
3. 在 Tampermonkey 中确认安装。
